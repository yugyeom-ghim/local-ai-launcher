# API 연결

기본 주소는 `http://127.0.0.1:1234/v1`입니다. 실행 중인 주소와 모델 ID는 **API 연결**에서 확인합니다.

## API 키

**API 키 사용 → 저장 후 시작 / 재시작**을 누릅니다. 생성된 키를 클라이언트에 입력합니다.
키는 `state/local-api-key.txt`에 저장되며 설정 내보내기에는 포함되지 않습니다.

## OpenCode

1. 서버 시작 후 **OpenCode 설정 내보내기**를 누릅니다.
2. 새 프로젝트는 `opencode.json`으로 저장합니다. 기존 설정에는 `provider.si-local`을 병합하고 `mcp`, `permission`, `agent` 설정을 유지합니다.
3. 인증을 켰다면 `/connect → Other → si-local`에 로컬 키를 입력합니다.
4. `/models`에서 **Local AI** 모델을 선택합니다.

**API 연결 → 문맥 크기**에서 4K~256K 프리셋을 선택하거나 **직접 입력 (토큰)**에 원하는 정수를 입력합니다. 저장 후 서버를 재시작하고, OpenCode 설정을 다시 내보낸 뒤 새 대화에서 확인합니다. 기본 4K와 기존 저장값은 유지합니다.

GGUF에 기록된 기준 문맥을 표시하며 **모델 기준값 사용**으로 적용할 수 있습니다. 메타데이터가 없으면 확인 불가로 표시하고 입력값은 유지합니다. 직접 입력은 512~2,147,483,647 범위이며 PC에서 실행 가능한 최대값을 뜻하지 않습니다. 문맥이 커질수록 메모리·처리 시간이 늘고, 기준 초과 입력만으로 YaRN이 자동 적용되지는 않습니다.
앱은 실제 실행 중인 문맥을 표시하며 내보낸 `limit.context`에도 같은 값을 사용합니다. 이미 한도를 넘은 대화는 요약 자체가 실패할 수 있습니다.

기존 MCP는 OpenCode가 실행합니다. 도구 호출 품질은 모델과 문맥 크기에 따라 달라집니다.
SI Copilot은 별도 VSIX이며, 해당 확장의 API 설정에 연결 정보를 입력합니다.

## 사고 모드

**모델**에서 ON/OFF를 선택하고 서버를 재시작합니다. 서버 기본값이며 모델 템플릿과 클라이언트 요청 옵션에 따라 적용됩니다.
