Local AI Launcher

설치
  인터넷 PC에서 Internet-PC-Download-Installer.exe를 실행합니다.
  생성된 Local_AI_Offline_Setup.exe 하나를 업무망으로 옮겨 실행합니다.
  다운로드·합치기: 여유 공간 9GB
  설치 중 다운로드는 없습니다.

환경
  Windows 10/11 x64, .NET Framework 4.8+, 여유 공간 6GB 이상
  CUDA: 호환 NVIDIA 드라이버 필요
  VC++ 런타임: prerequisites/vc_redist.x64.exe

업데이트
  서버와 앱을 종료하고 기존 폴더에 설치합니다.
  설정·API 키·추가 모델은 유지됩니다. 제거 후에도 남습니다.

사용
  모델·실행기·사고 모드 선택 → 서버 시작
  API 연결 → 주소·모델 ID·키 복사 / OpenCode 설정 내보내기
  모델 추가: offline-assets/ai/models에 GGUF 저장
